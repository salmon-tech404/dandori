## Tóm tắt cho người không rành kỹ thuật
Module `diff-preview` (Xem trước khác biệt mã nguồn và môi trường chạy thử) cho phép người dùng quan sát trực tiếp các thay đổi file mã nguồn sau khi AI agent thực hiện công việc. Người dùng có thể xem danh sách các file đã thay đổi, số dòng thêm/bớt, nội dung diff dạng tô màu cú pháp theo từng file, tải file preview hoặc bật server xem trước (preview server) trên máy cục bộ với lệnh an toàn (không dùng shell độc hại, chặn cổng nguy hiểm, chỉ cho phép cổng loopback). Mọi truy cập vào diff và preview đều được bảo vệ chặt chẽ theo phân quyền không gian làm việc (workspace isolation/BOLA).

## Tự đánh giá & Bài học
- Windows File System path traversal: Khi kiểm thử path traversal trên Windows NTFS, một số ký tự đặc biệt như `<`, `>` không thể tạo thành file vật lý do quy định của hệ điều hành NTFS. Do đó bài test XSS filename được kiểm tra ở tầng Frontend component (Vitest) và bộ parse numstat.
- Kiểm soát tiến trình: Dùng `std::process::Command` với mảng đối số tách rời, tuyệt đối không dùng shell wrapper (`sh -c` hoặc `cmd /C`) để phòng chống hoàn toàn Command Injection.
- Dọn dẹp tiến trình con: Luôn đảm bảo khi module bị tắt (`disable`) hoặc server tắt (`shutdown`), các tiến trình preview con đang chạy ngầm phải được gửi tín hiệu `kill` ngay lập tức để không rò rỉ tài nguyên hệ thống.
