## 1. Công việc đã thực hiện

### Backend: Crate `crates/mod-prompt-library`
- `module.json`: group `knowledge`, requires `["lead-worker"]`, scopes `["workspace", "project"]`, contributes slot `knowledge.tab` (id: `prompt-library-tab`, order 10).
- Migration `0001_prompt_library.sql`:
  - `m_prompt_library_prompt`: `id`, `workspace_id`, `project_id`, `name`, `role`, `skill_tag`, `current_version`, `created_at`, `updated_at`.
  - `m_prompt_library_version`: `id`, `prompt_id`, `version`, `content`, `created_at`, khóa duy nhất `(prompt_id, version)`.
- `template.rs`:
  - Kiểm tra độ dài tối đa 10,000 ký tự (`check_length`).
  - Phát hiện và chặn các tiền tố chuỗi khóa nhạy cảm / API token (`check_secrets`): `sk-`, `ghp_`, `gho_`, `glpat-`.
  - Xác thực danh sách trắng các biến cho phép (`validate_variables`): `{{task.title}}`, `{{task.description}}`, `{{project.name}}`, `{{role}}`.
  - Thuật toán kết xuất biến một lượt quét (`render_template`), chống đệ quy (nếu `task.title` chứa `{{role}}` thì giữ nguyên không bị giải mã tiếp).
- `contributor.rs`:
  - Hiện thực trait `PromptContributor` cho `PromptLibraryContributor`.
  - Lọc prompt theo vai trò thực thi (`pm`/`worker`/`test`/`doc`/rỗng) và dự án, sinh ra các `PromptPart` có nhãn nguồn `prompt-library:<name>:v<version>`.
- `handlers.rs`:
  - `GET /api/v1/m/prompt-library/prompts`: Lấy danh sách prompt theo workspace.
  - `POST /api/v1/m/prompt-library/prompts`: Tạo prompt mới và phiên bản v1 ban đầu.
  - `GET /api/v1/m/prompt-library/prompts/{id}`: Xem chi tiết prompt và nội dung phiên bản hiện tại.
  - `PUT /api/v1/m/prompt-library/prompts/{id}`: Cập nhật prompt và sinh phiên bản mới tăng dần.
  - `GET /api/v1/m/prompt-library/prompts/{id}/versions`: Xem toàn bộ lịch sử phiên bản.
  - `POST /api/v1/m/prompt-library/prompts/{id}/restore/{version}`: Khôi phục phiên bản cũ bằng cách tạo phiên bản mới với nội dung cũ.
  - `POST /api/v1/m/prompt-library/prompts/test-render`: Thử kết xuất prompt với các tham số mẫu mà không gọi agent.
- `lib.rs`: Hiện thực hợp đồng `Module` cho `PromptLibraryModule`.

### Frontend: Tính năng `frontend/app/src/features/prompt-library/`
- `types.ts`: Các interface `PromptSummary`, `PromptDetail`, `PromptVersion`, `TestRenderResult`.
- `usePromptLibrary.ts`: Custom hook nạp dữ liệu và các hàm gọi API RESTful.
- `PromptEditorModal.tsx`: Hộp thoại tạo mới / chỉnh sửa prompt, đếm số ký tự, cảnh báo trực tiếp khi nhập token nhạy cảm (`sk-`, `ghp_`).
- `TestRenderModal.tsx`: Hộp thoại thử kết xuất prompt với các biến mẫu (Task title, Task desc, Project name, Role).
- `VersionHistoryModal.tsx`: Xem lịch sử các phiên bản của prompt và nút bấm khôi phục phiên bản.
- `PromptLibraryTab.tsx`: Bảng danh sách prompt, hiển thị badge vai trò, nhãn kỹ năng, phiên bản `vN`, ngày cập nhật và các nút thao tác.
- `index.tsx`: Đăng ký đóng góp slot `prompt-library-tab` vào slot `knowledge.tab`.
- `promptLibrary.test.tsx`: 5 bài kiểm thử unit/component kiểm tra đóng góp slot, cảnh báo token, kết xuất thử và duyệt lịch sử.
- `i18n.ts`: Bổ sung toàn bộ chuỗi đa ngôn ngữ tiếng Việt cho Thư viện prompt.
