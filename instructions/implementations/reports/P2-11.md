## 1. Mục tiêu và Phạm vi Task P2-11

Triển khai module `mod-api-key-fallback` (thuộc nhóm `accounts`, effort `medium`, risk `high`, phụ thuộc `auth-login`) làm phương án dự phòng khi tài khoản gói (CLI subscription) cạn hạn mức:
1. **Bảo vệ khóa API trong Két bảo mật (Vault):**
   - Khóa API trả phí (`claude`, `codex`, `agy`) được mã hóa AES-256-GCM qua `dandori-vault` bằng master key dùng chung (`MemoryKeyStore::shared()`).
   - Cột `label` của secret và API phản hồi chỉ hiển thị masked key (`••••••••••••{last4}`). Tuyệt đối không lưu plain text ở cơ sở dữ liệu hay log hệ thống.
   - Khi xóa tài khoản API key, khóa được giải phóng khỏi két bảo mật (`vault.reveal` trả về `NotFound`).
2. **Bắt buộc thiết lập Trần chi tiêu (Spending Limit):**
   - Bắt buộc cấu hình trần chi tiêu (`spending_limit`: `period`, `limit_type`, `limit_value > 0`, `alert_threshold`) trước khi cho phép kích hoạt tài khoản (`enabled = 1`).
   - Cố bật tài khoản khi chưa có trần chi tiêu sẽ bị từ chối với HTTP 400 Bad Request.
   - Khi chi tiêu chạm ngưỡng cảnh báo (`alert_threshold`), phát sự kiện `notification.requested` (`EventPayload::NotificationRequested`).
   - Khi chạm trần chi tiêu (`used_value >= limit_value`), tự động tắt tài khoản (`enabled = 0`, gán `exhausted_until`) và phát thông báo cảnh báo.
3. **Chính sách Dự phòng (Fallback Policy):**
   - Mặc định ưu tiên 100% tài khoản gói (CLI) để tiết kiệm chi phí.
   - `RunService::start_run` tự động loại bỏ các tài khoản `api_key` trừ khi dự án đã bật `fallback_enabled = 1` trong `m_api_key_fallback_project_config`.
   - Khi tài khoản CLI cạn hạn mức (`exhausted_until`) hoặc không có tài khoản CLI khả dụng, VÀ dự án đã bật dự phòng, hệ thống tự động chọn tài khoản API key dự phòng, giải mã khóa qua Vault và tiêm vào biến môi trường tiến trình con (`ANTHROPIC_API_KEY`, v.v.).
4. **Kiểm soát quyền truy cập và cô lập Workspace (BOLA Check):**
   - Chỉ quản trị viên hệ thống (`system_role == 'admin' | 'owner'`) mới có quyền quản lý tài khoản API key (`/accounts`).
   - Người dùng không thuộc workspace của dự án bị từ chối truy cập hoặc sửa đổi cấu hình dự phòng dự án với HTTP 403 Forbidden.
5. **Giao diện Người dùng Frontend:**
   - `ApiKeyFallbackCard.tsx`: Thẻ hiển thị danh sách tài khoản API key với masked key, thanh tiến trình chi tiêu (đổi màu cảnh báo vàng/đỏ), nút bật/tắt và xóa.
   - `AddApiKeyModal.tsx`: Hộp thoại thêm khóa API mới kèm cấu hình trần chi tiêu bắt buộc.
   - `ProjectFallbackConfigCard.tsx`: Thẻ cấu hình chính sách dự phòng theo từng dự án trong cài đặt dự án.
