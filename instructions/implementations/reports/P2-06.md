## 1. Mục tiêu và Phạm vi Task P2-06

Triển khai module `mod-integrations` (thuộc nhóm `integrations`, effort `heavy`, phụ thuộc `auth-login`) và điểm mở rộng kiến trúc `GitHostProvider` theo đúng đặc tả:
1. **Điểm mở rộng `GitHostProvider`:**
   - Khai báo tại `crates/dandori-module-api/src/extension.rs` với các phương thức cốt lõi: `test_connection`, `create_pull_request`, `get_pull_request`, `get_ci_status`, `merge_pull_request`.
   - Các cấu trúc dữ liệu đi kèm: `CreatePullRequestPayload`, `RemotePullRequest`, `CiStatusSummary`, `CiState`, `MergeMethod`, `MergeResult`, `GitHostError`.
   - Quản lý vòng đời trong `FeatureLifecycleManager` (`git_host_provider`).
2. **Module `mod-integrations`:**
   - Hiện thực `GitHubProvider` cho GitHub REST API.
   - Hiện thực `GitLabProvider` cho GitLab REST API v4.
   - Hiện thực `LinearClient` cho Linear GraphQL API (`viewer`, `issues`, nhập issue vào `task` backlog kèm deduplication).
   - Dynamic provider router `DynamicGitHostProvider` kết nối DB `m_integration_connection`.
3. **Bảo mật và SSRF (SEC-SSRF-001, ADR 0006):**
   - URL & domain validation: GitHub chỉ chấp nhận `api.github.com`, Linear chỉ chấp nhận `api.linear.app`.
   - Chặn tuyệt đối loopback (`127.0.0.1`, `localhost`) trong production; chặn metadata cloud (`169.254.169.254`); chặn mạng riêng RFC 1918 trừ khi `allow_private_network: true` (GitLab self-hosted).
   - Client an toàn với giới hạn timeout 15s, response body limit 2MB, redirect boundary enforcement.
   - Personal Access Token (PAT) không bao giờ bị trả về qua API và được che chắn trong thông điệp lỗi (`[REDACTED_TOKEN]`).
4. **Giao diện người dùng Frontend:**
   - `frontend/app/src/features/integrations/` đóng góp thẻ cài đặt `integrations.settings` tại màn hình Cài đặt (`settings.integrations`).
   - Hỗ trợ thêm kết nối mới, kiểm tra trước kết nối (Preflight test), hiển thị danh sách kết nối (không lộ token) và xóa kết nối.
