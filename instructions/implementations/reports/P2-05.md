## Tóm tắt cho người không rành kỹ thuật
Module `doc-agent` bổ sung vai trò tự động cập nhật tài liệu dự án (như hướng dẫn trong `docs/**`, `README.md`, `CHANGELOG.md`) khi một nhiệm vụ đã được duyệt mã nguồn và sẵn sàng tích hợp (`ready_to_merge`). Doc agent hoạt động trực tiếp trên cùng thư mục làm việc (worktree) của nhiệm vụ đó. Hệ thống có cơ chế kiểm soát nghiêm ngặt: doc agent chỉ chạy tối đa 1 lần duy nhất cho mỗi nhiệm vụ tại trạng thái `ready_to_merge` để chống vòng lặp vô tận (anti-loop). Sau khi kết thúc, hệ thống tự động kiểm tra danh sách tệp thay đổi và gắn cờ cảnh báo nếu doc agent can thiệp trái phép vào các tệp mã nguồn bên ngoài phạm vi tài liệu cho phép.

## Đã làm
- **Crate Module `crates/mod-doc-agent/`:**
  - `module.json`: nhóm `orchestration`, phụ thuộc `["lead-worker"]`, phạm vi `workspace` và `project`. Đóng góp slot giao diện: `board.task-panel.section` (Tài liệu), `settings.section` (Cấu hình Doc Agent).
  - Migration SQL `0001_doc_agent.sql`: tạo hai bảng `m_doc_agent_config` và `m_doc_agent_run`.
  - `pattern.rs`: Bộ kiểm tra khớp mẫu đường dẫn glob (`docs/**`, `README*`, `CHANGELOG*`) kiểm soát tệp hợp lệ được phép sửa đổi.
  - `worker.rs`: Bộ xử lý sự kiện nền `run_doc_agent_worker`:
    - Lắng nghe `TaskStatusChanged`: khi `new_status == "ready_to_merge"`, kiểm tra `can_trigger_doc_agent` (module bật, chưa có lượt chạy nào đang chạy hoặc hoàn thành cho task). Gọi `runner.start_run(task_id, AgentRole::Custom("doc"), user_id, vec![])`.
    - Lắng nghe `RunFinished`: khi lượt chạy doc agent hoàn tất, quét worktree qua `GitClient.status_porcelain`, phân loại tệp hợp lệ (`changed_doc_files`) và tệp bị gắn cờ ngoài phạm vi (`flagged_files`), cập nhật bản ghi `m_doc_agent_run`. Chống lặp vô tận: lượt chạy doc agent kết thúc không tự kích hoạt thêm doc agent mới.
  - `handlers.rs` & `routes.rs`:
    - `GET /projects/:project_id/config`: Lấy cấu hình doc agent của dự án.
    - `PUT /projects/:project_id/config`: Cập nhật cấu hình doc agent của dự án.
    - `GET /tasks/:task_id/results`: Lấy danh sách kết quả doc agent cho task.
    - `GET /runs/:run_id/result`: Lấy kết quả doc agent theo run_id.

  - `index.ts`: Xuất các đóng góp slot `doc-agent-task-section` và `doc-agent-project-settings`.
  - `docAgent.test.tsx`: Bộ kiểm thử giao diện bằng Vitest kiểm tra hiển thị trạng thái rỗng và kết quả doc agent.
  - Bổ sung từ điển đa ngôn ngữ chuẩn trong `frontend/app/src/core/i18n.ts`.
